# Illustrations

Drop generated images here using the exact filenames below — the UI code will
reference them at `/illustrations/<filename>` once wired in. Prompts kept
here so this stays the single source of truth as more get added.

Brand style baseline (keep consistent across all): teal-to-violet gradient
(`from-teal-400 to-violet-400`), dark navy background, thin-line vector
style, no text baked into the image, no photorealism.
